Summary
In today's lecture, we explored web services and object-oriented distributed programming, beginning with Java RMI (Remote Method Invocation) as a mechanism for calling methods across networked machines. We examined how RMI uses client-side stubs and server-side implementations to abstract away network complexity, allowing developers to invoke remote methods as if they were local, with an RMI registry managing service bindings between clients and servers. Through a practical calculator example, we demonstrated how to create an RMI interface, implement it on the server side, and access it from a client by looking up the service in the registry and casting the returned object. However, we discussed significant limitations of Java RMI, including its Java-specific nature, security vulnerabilities related to arbitrary code execution and deserialization attacks, and compatibility issues across different Java virtual machines. This led us to explore the foundational web technologies created by Tim Berners-Lee: HTML as a markup language for structuring content, URLs and URIs for identifying and locating resources, and HTTP as the protocol for transferring data. We introduced HTTP methods such as GET, POST, PUT, and DELETE, which define actions on resources identified by URIs, setting the stage for understanding modern web service architectures that prioritize sending data rather than executable code over networks.
