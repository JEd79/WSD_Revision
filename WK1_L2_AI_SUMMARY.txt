Summary
In today's lecture, we explored network communication protocols and distributed computing fundamentals, beginning with a detailed examination of UDP and TCP protocols and their key differences in handling packet ordering and reliability. We discussed how UDP operates as a connectionless, stateless protocol where packets may arrive out of order, while TCP guarantees ordered delivery through connection establishment and packet sequencing. The lecture then introduced the layered architecture of network communication, showing how application data gets encapsulated through multiple protocol layers including transport, IP, and data link layers, each adding specific information like ports, IP addresses, and MAC addresses. We examined practical security implications of these protocols, particularly how UDP's lack of source verification enables amplification attacks where attackers can spoof packet origins to redirect traffic to victims. Moving into practical implementation, we explored Java sockets as abstractions that handle the complexity of these lower layers, distinguishing between ServerSocket and Socket for TCP connections and DatagramSocket for UDP communication. We demonstrated creating a simple TCP server-client application using PrintWriter and BufferedReader for bidirectional communication, showing how changing only the IP address allows the same code to work across networks. We then implemented a UDP example using DatagramPacket to send fixed-size byte arrays, highlighting the challenges of manual byte array management compared to stream-based TCP communication. Finally, we introduced Java RMI (Remote Method Invocation) as a higher-level abstraction that allows clients to call methods on remote server objects as if they were local, demonstrating how distributed computing enables work to be performed on servers with results returned to clients over the network.
